# Portfolio Website

This project generates a personal portfolio website from a `data.yaml` configuration file and HTML templates. 
It also automatically generates a `sitemap.xml` and `robots.txt` for improved SEO.

[https://stevendeleon.com](https://stevendeleon.com)

## Features

*   **Dynamic Content Generation:** Builds the `index.html` and `404.html` pages based on data defined in `data.yaml`.
*   **Templating:** Uses Go's `html/template` package for flexible and maintainable HTML generation.
*   **Sitemap Generation:** Automatically creates a `sitemap.xml` to help search engines crawl the site.
*   **Robots.txt Generation:** Creates a `robots.txt` file to instruct search engine crawlers.
*   **Theme:** It has light/dark & system built-in based on the `nord` colorscheme: [nordtheme](https://www.nordtheme.com/)

## Technologies Used
